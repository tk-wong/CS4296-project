# Experiment data
This directory contains the data collected from the experiments, which is the CSV file generated by the test script. The CSV file contains the latency data collected from the experiments, which will be used for analysis and comparison.

## Structure
`cold start test`: The directory contains the CSV files generated from the cold start test.
`load test`: The directory contains the CSV files generated from the load test. 

Each CSV file corresponds to a different server and contains the latency data collected from the load test for that server. They can be identified by the name of the server in the file name. For example, the file "load-lambda.csv" contains the latency data collected from the load test for the function deployed on AWS Lambda.
